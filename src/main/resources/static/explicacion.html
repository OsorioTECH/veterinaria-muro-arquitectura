📘 Explicación Entrega 1

Esta sección explica la lógica y estructura aplicadas en el desarrollo del módulo de gestión de clientes, incluyendo las capas implementadas, las tecnologías utilizadas y la razón de cada decisión técnica.

1. Lógica general aplicada

El objetivo fue desarrollar una sección funcional aplicando el enfoque de arquitectura por capas, buscando mantener el código ordenado, escalable y fácil de mantener. Cada capa cumple un rol específico dentro del sistema, lo que permite modificar partes del proyecto sin afectar el resto.

2. Capas implementadas

  • Capa API: Recibe las peticiones del usuario y maneja las rutas HTTP.
  • Capa de Aplicación: Contiene la lógica del negocio y valida los datos antes de guardarlos.
  • Capa de Dominio: Define las entidades y las interfaces principales del sistema.
  • Capa de Infraestructura: Se encarga de guardar y consultar la información en la base de datos.
  • Capa Compartida: Maneja errores globales y mensajes claros para el usuario.

3. Tecnologías utilizadas

El proyecto utiliza las siguientes herramientas y tecnologías:

  • Java 21: Lenguaje principal de desarrollo.
  • Spring Boot: Framework para estructurar el proyecto por capas.
  • Spring Web: Para manejar las solicitudes HTTP.
  • Spring Data JPA + H2: Para la conexión y persistencia de datos.
  • HTML, CSS y JavaScript: Para el desarrollo de la interfaz visual.

4. Persistencia de datos

Se configuró la base de datos H2 en modo archivo (jdbc:h2:file:./data/vetedb) para garantizar que los datos se mantengan guardados incluso si se apaga el servidor o el computador.

5. Conclusión

Con esta entrega se demuestra el entendimiento del modelo por capas, la separación de responsabilidades y la integración entre el backend (Java con Spring Boot) y el frontend (HTML, CSS y JS). Además, se añadió esta sección explicativa como aporte extra, mostrando la documentación del proyecto directamente dentro de la plataforma.
