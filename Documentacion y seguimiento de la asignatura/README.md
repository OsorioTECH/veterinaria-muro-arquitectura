# Veterinaria Muro - Documento de Arquitectura de Software

Este repositorio contiene el **documento de arquitectura de software** y los artefactos relacionados con el proyecto **"Aplicación Veterinaria Muro"**, desarrollado en el curso **Arquitectura de Software**.

La aplicación busca modernizar la gestión de procesos internos de la veterinaria, incluyendo:
- Gestión de clientes y mascotas
- Gestión de citas
- Facturación y servicios
- Exámenes clínicos
- Administración de usuarios
- Generación de informes

## Contenido del repositorio
- `index.html`: Documento de arquitectura con navegación lateral (tabla de contenidos).
- `img/`: Carpeta con diagramas UML e imágenes de apoyo.
- `README.md`: Descripción general del proyecto.

## Objetivo académico
Este trabajo tiene como finalidad aplicar los principios de **arquitectura de software** sobre un proyecto en este caso una Aplicación Veterinaria, siguiendo buenas prácticas de documentación, diseño y organización.
